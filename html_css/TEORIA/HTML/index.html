BOX MODEL

O Box Model (Modelo de Caixa) do CSS é o conceito fundamental que dita como todos os elementos HTML são renderizados e visualizados na tela. Ele trata cada elemento como uma caixa retangular composta por quatro camadas principais: Conteúdo, Preenchimento (Padding), Borda e Margem.As 4 Camadas do Box ModelCada camada tem um propósito específico e interage diretamente com o tamanho total do elemento:Content (Conteúdo): O núcleo da caixa, onde textos, imagens, vídeos ou outros elementos são exibidos. Seu tamanho é definido pelas propriedades width (largura) e height (altura).Padding (Preenchimento): O espaço transparente entre o conteúdo e a borda. Serve para dar "respiro" interno ao elemento (ex: o espaço dentro de um botão).Border (Borda): A linha que envolve o conteúdo e o padding. Pode ser estilizada em espessura, cor e estilo (sólida, tracejada, etc.).Margin (Margem): O espaço transparente fora da borda. É usado para afastar ou distanciar o elemento de outros elementos ao redor.

HTML

HTML (HyperText Markup Language ou Linguagem de Marcação de Hipertexto) é o bloco de construção fundamental da internet. Ele não é uma linguagem de programação, mas sim uma linguagem de marcação que utiliza tags (marcadores) para estruturar e apresentar o conteúdo de uma página web.O HTML define onde ficam textos, parágrafos, imagens, tabelas e links. Ele trabalha em conjunto com o CSS (que cuida do visual e estilo) e o JavaScript (que adiciona interatividade e comportamento).

Não é uma linguagem de programação, mas sim um sistema de "etiquetas" (tags) usado para estruturar e organizar o conteúdo de uma página web, como textos, links, vídeos e imagens.

CSS

O CSS (Cascading Style Sheets ou Folhas de Estilo em Cascata) é a linguagem de estilização usada para definir a aparência visual de documentos HTML ou XML. Enquanto o HTML cuida da estrutura, o CSS controla cores, fontes, espaçamentos, layouts e responsividade, transformando o código em um design atraente.Como o CSS FuncionaO CSS atua aplicando estilos a elementos HTML específicos selecionados em sua página.
